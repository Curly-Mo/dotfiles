# input-leap config

- Client mode connecting to server host `windoze` with clipboard sharing enabled
- TLS encryption, auto-start, minimize to tray

## Files

- **`InputLeap.conf`**
  - Screen name: `lappybara`
  - Server hostname: `windoze` on port 24800
  - Clipboard sharing enabled with 100MB size limit
  - TLS encryption enabled, client certificates not required
  - Auto-start on login, auto-hide to tray, screensaver sync on
  - Drag and drop enabled
  - Logging level 3 (info), log to file disabled
  - 5x3 grid layout with 15 screen slots
