# helix config

- Carbonfox color theme
- Cursor shape varies by mode: bar in insert, block in normal, underline in select

## Files

- **`config.toml`**
  - Sets theme to `carbonfox`
  - Insert mode cursor: bar
  - Normal mode cursor: block
  - Select mode cursor: underline
