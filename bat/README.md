# bat config

- Uses the `ansi` theme for terminal-native color rendering
- Enables auto color and auto decorations

## Files

- **`config`**
  - `--theme="ansi"` - Uses ANSI colors instead of a fixed theme, adapting to terminal palette
  - `--color="auto"` - Color output when connected to a terminal
  - `--decorations="auto"` - Shows line numbers and git changes when appropriate
  - `--style="auto"` - Auto-selects header, line numbers, and grid based on context
