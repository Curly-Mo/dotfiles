# libinput-gestures config

- 3-finger swipe up/down for Alt+Tab window switching
- 3/4-finger swipe left/right for workspace navigation
- 4-finger swipe up/down for vertical workspace switching

## Files

- **`libinput-gestures.conf`**
  - 3-finger swipe up: `Alt+Tab` (switch to next window)
  - 3-finger swipe down: `Shift+Alt+Tab` (switch to previous window)
  - 3-finger swipe left: next workspace
  - 3-finger swipe right: previous workspace
  - 4-finger swipe left: next workspace (same as 3-finger)
  - 4-finger swipe right: previous workspace (same as 3-finger)
  - 4-finger swipe up: workspace up (vertical)
  - 4-finger swipe down: workspace down (vertical)
