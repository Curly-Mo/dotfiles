# opencode config

- Sets Claude Sonnet 4.5 as the default model
- Enables automatic updates

## Files

- **`.config/opencode/opencode.jsonc`**
  - `model: anthropic/claude-sonnet-4-5` — default model
  - `autoupdate: true` — automatically updates OpenCode on launch
